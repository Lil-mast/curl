# ops/

How we run Maktab AI. No secret values in git.

## Belongs here (when T1.4 / T1.5 start)

- Env var **names**: `DATABASE_URL`, `ELEVENLABS_API_KEY`, `NEXT_PUBLIC_API_URL`, `ALLOWED_ORIGIN`
- Render service names (Next.js + Flask)
- Neon project / branch names (not connection strings)
- What to do if ElevenLabs or Neon is down
- How partners report a wrong knowledge entry (**T6.3**)

## Never belongs here

- API keys, account passwords, user recordings
